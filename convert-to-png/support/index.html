Convert

  • Drop image files on the window, or browse to pick them.
  • Choose an output folder.
  • Click Start. Each file becomes a PNG at full size, with its transparency kept.

Formats

  • JPG, PNG, GIF, BMP, TIFF, TGA, PSD, OpenEXR, WebP, HEIC and HEIF.

Tips

  • Replace existing files overwrites a PNG of the same name. Leave it off and the new copy is saved as "name 2.png".
  • Reset Failed clears failed files from the list.
  • Clear empties the list. It does not delete any files.
